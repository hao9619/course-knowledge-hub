# 第三方来源与许可

## 代码与依赖

项目由既有 Agent 项目参考、复用和改造而来，当前归档只保留课程应用入口使用的源码。没有为未经确认的既有代码统一追加开源许可证。前后端直接依赖与锁定版本见各自的 `package.json`、`package-lock.json`；安装的第三方组件以其随附许可为准。
